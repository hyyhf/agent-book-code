# FunHarness Studio v1.1.0

本次更新重点改善多轮对话导航、大工作区文件访问与任务完成后的阅读体验：更快找到历史问题、更方便引用深层文件，并把执行过程和最终交付物整理清楚。

## 主要更新

### 对话轮次导航

- 对话区左侧新增轮次刻度栏，悬停即可预览每轮用户输入，点击跳转到对应位置。
- 默认刻度短小、等宽；悬停时当前刻度与邻近刻度渐进伸展，形成平滑的山峰过渡。
- 支持方向键及 Home / End 导航。查看历史消息时，新的流式输出不会强制把视图拉回底部。

### 大工作区加载与文件引用优化

- 优化目录读取、分页与缓存，减少大工作区打开时的等待和重复读取。
- 只输入 `@` 时展示工作区根目录的文件与文件夹；输入关键词后再搜索子目录。
- 搜索结果显示相对路径，方便区分不同目录中的同名文件。

### 更流畅的工作区拖拽

- 优化流式输出期间拖动工作区宽度的响应，减少重复布局计算和界面更新。
- 拖动过程中对话实时换行、输入框同步适配，松开时保持当前排版。
- 调整宽度时尽量保持正在阅读的位置，并改善底部滚动跟随。

### 任务耗时与执行过程折叠

- 每轮任务顶部实时显示处理时长；完成后保留本轮最终耗时。
- 只有确认整个任务正常完成后，才以过渡动画折叠思考、工具调用与中间回复，最终答复保持可见。
- 中间 AI 回复不会触发折叠；停止、失败或达到执行上限时保留过程展开。
- 点击完成耗时可重新展开过程。新记录保存起止时间，重新打开会话后耗时保持固定。

### 本轮产物卡片

- 最终答复下方新增「本轮产物」，展示最终答复引用、且本轮生成或修改的工作区交付文件。
- 文档、表格、图片、视频、音频、脚本与压缩包使用不同图标，并显示文件大小和所在目录。
- 默认展示两项，其余可展开；点击卡片可在系统文件管理器中定位文件。
- 排除临时目录、缓存及仅在中间执行过程中出现的文件；明确交付的分析日志和脚本可以保留。
- 产物信息随会话保存。文件已移动或删除时给出提示，避免误创建同名文件夹。

## 项目展示更新

README 新增由 **16 张原始截图**排版导出的正方形海报，补充概念工坊、心智庭院等界面图集，并提供 GIF 速览与可直接播放的演示视频。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `FunHarness Studio Setup 1.1.0.exe` | Windows x64 安装包，约 242 MB |
| `FunHarness Studio v1.1.0-win64-portable.zip` | Windows x64 免安装版，约 301 MB |
| `SHA256SUMS-v1.1.0.txt` | 安装包与免安装版的 SHA-256 校验值 |

两个版本均包含桌面端与独立 Python 后端，无需另行安装 Python。

升级前请结束正在执行的任务并退出 Studio。免安装版需完整解压后运行 `FunHarness Studio.exe`，保留同目录的 `resources` 等文件；使用原工作区路径即可继续访问已有数据。升级后请完整重启应用，使桌面端与后端的新功能一起生效。

旧会话缺少运行时间或交付物元数据时，保持原有展示，不补造耗时和产物记录。

## 验证情况

- 前端生产构建与 Electron 安全检查通过。
- 独立后端启动、健康接口及认知冲刺相关流程检查通过。
- 打包后的桌面应用启动、主要页面导航与窄窗口布局检查通过。
- 便携 ZIP 完整性检查通过，并附 SHA-256 校验文件。
