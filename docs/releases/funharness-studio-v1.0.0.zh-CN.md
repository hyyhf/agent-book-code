# FunHarness Studio v1.0.0

本次更新汇总 2026 年 9 月 28 日至 10 月 4 日的改进，重点增强 Agent 的图片理解、长任务运行稳定性与高频文件编辑效率，同时优化聊天附件展示。

## 主要更新

- **统一读图入口**：`tool_read_file` 自动识别文本和图片。上传的图片、Agent 自行生成的截图均可作为视觉内容进入后续推理，主 Agent、子 Agent 和群组共用多模态处理能力；已通过 DeepSeek `deepseek-flash` 实际 API 验证。文本默认读取上限从 12 万提高到 **30 万字符**，支持按行读取。
- **上下文超限恢复**：推理前估算输入预算并预留输出空间，必要时压缩历史与过长工具结果；遇到上下文超限时自动缩减并有限重试，保存恢复状态，改善重发“继续”仍被同一超限错误阻塞的问题。
- **可管理的命令执行**：长命令短暂等待后返回任务编号，可继续查询输出、等待或取消；执行期限与单次等待分离，常驻服务支持显式后台运行。完善超时、停止操作、后端退出时的进程树清理，减少卡住与遗留终端。
- **原生 PowerShell 支持**：除 CMD 外，可选择 Windows PowerShell 5.1 或 PowerShell 7，改善中文、带空格路径、多行脚本、引号及退出码处理。
- **更高效、可靠的文件编辑**：`tool_replace_in_file` 支持批量替换与显式全部替换，结合缓存、局部 diff 和无变化跳过，减少重复读取、写入及界面传输；增加原子写入、文件版本校验、歧义与重叠检查，并保留 BOM、换行格式及文件末尾状态。
- **更紧凑的附件展示**：发送成功后，附件从输入框移至对应用户消息气泡上方；图片缩略图与文件卡片高度统一为 **50px**，支持历史消息恢复，发送失败时保留待发送附件。
- **桌面打包修复**：修正概念桌面两张装饰图在安装版中的资源路径，更新打包后的界面验证脚本。

## 下载与升级

- `FunHarness Studio Setup 1.0.0.exe`：Windows x64 安装包，包含桌面端与 Python 后端运行环境。
- `FunHarness Studio v1.0.0-win64-portable.zip`：Windows x64 免安装版，完整解压后运行 `FunHarness Studio.exe`。
- `SHA256SUMS-v1.0.0.txt`：安装包与免安装版的 SHA-256 校验值。

升级前请退出正在运行的 FunHarness Studio。图片理解需要使用支持视觉输入的模型；PowerShell 7 需要本机安装 `pwsh`。本版已支持文本和图片，音频与视频输入尚未开放。

文件编辑默认只替换唯一匹配项；需要替换全部匹配时请显式使用 `replace_all=true`。检测到文件已被其他操作修改时，需重新读取后再编辑。
